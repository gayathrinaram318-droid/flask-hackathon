# 📚 Study Planner

A simple and user-friendly web application built with Flask to help students organize study tasks, manage deadlines, reminders, and track progress.

## 🚀 Live Demo
[open study planner](https://flask-hackathon.onrender.com)

## ✨ Features

- 🔐 User Registration and Login
- 📝 Create and manage study tasks
- 📅 Set task deadlines
- ⏰ Manage reminders
- 📊 Track study progress
- 🗃️ SQLite database for storing data
- 🎨 Clean and responsive user interface

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

- app.py

- static/style.css

- templates/dashboard.html

## ⚙️ How to Run Locally

1. Clone the repository:
   git clone https://github.com/gayathrinaram318-droid/flask-hackathon.git
2. Open the project folder:
   cd flask-hackathon
3. Install the required packages:
   pip install -r requirement.txt
4. Run the Flask application:
   python app.py
5.The application will run locally on your computer.

## 🎯 Purpose

The Study Planner provides students with a simple digital platform to organize academic tasks, manage deadlines, and track study progress.
